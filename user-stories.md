User Stories — Recipe and Meal Planner App
1. Account Registration

As a new user, I want to create an account using my name, email, age, and password, so that I can save my meal plans and preferences across sessions.

2. Login

As a returning user, I want to log in with my email and password, so that I can securely access my saved recipes and meal plans.

3. Home / Recipe Discovery

As a user, I want to browse a curated list of recipes on the home screen, so that I can quickly find meal inspiration without searching manually.

4. Recipe Detail Screen

As a user, I want to view a recipe's full details — including ingredients, prep time, and step-by-step instructions — so that I can decide whether to cook it and follow along easily.

5. Meal Planning / Weekly Calendar

As a user, I want to add recipes to specific days on a weekly meal calendar, so that I can plan my meals in advance and stay organized.

6. Shopping List Generation

As a user, I want the app to automatically generate a shopping list based on the ingredients from my planned meals, so that I don't have to manually compile a grocery list.

7. Favorites / Saved Recipes

As a user, I want to save recipes I like to a Favorites list, so that I can quickly find and reuse them without searching again.

8. Notifications

As a user, I want to receive reminders about upcoming planned meals, so that I remember to prep or shop in time.

9. Settings

As a user, I want to manage my account settings — including dietary preferences, theme (light/dark mode), and notification preferences — so that I can personalize the app to fit my needs.
